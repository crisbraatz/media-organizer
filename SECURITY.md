# Security policy

## Supported versions

Fixes are developed on `main` and distributed in the latest stable release. See [GitHub Releases](https://github.com/crisbraatz/media-organizer/releases) for the current version.

## Reporting a vulnerability

Use the repository's [private vulnerability reporting form](https://github.com/crisbraatz/media-organizer/security/advisories/new) if it is available. If you cannot access the form, open a [GitHub issue](https://github.com/crisbraatz/media-organizer/issues/new) asking for a private contact route. Keep the issue title and description free of vulnerability details.

In the private report, include the version, operating system, relevant command or options, impact and steps to reproduce. Use synthetic files and redact personal paths and credentials. If the issue could damage data, describe the affected operation and the resulting file state.

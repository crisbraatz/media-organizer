# Code of conduct

Everyone taking part in Media Organizer's issues, pull requests and other project spaces is expected to treat others with respect. Welcome questions, give feedback about the work and respect people's privacy.

Harassment, discriminatory language, threats, sexualized comments and sharing someone's private information without consent are unacceptable.

Report a concern to the maintainers privately using a contact method they have published. If you need a private route, use [GitHub Issues](https://github.com/crisbraatz/media-organizer/issues/new) to request one without posting names, evidence or personal details. For abuse on GitHub, you can also use the platform's reporting tools.

Maintainers may remove content, warn participants or restrict participation, depending on the impact and whether the behavior recurs. They should limit access to reported details to people who need them to respond.
